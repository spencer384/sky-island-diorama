# 天空島 · Floating Sky Island Diorama (Web 3D)

Interactive Three.js WebGL floating sky island diorama featuring a **Taiwan Railways (TRA) CK124** 2-6-2T steam locomotive pulling classic blue ordinary passenger carriages (`台鐵藍皮普快車`) around a floating island village.

## Features
- **TRA CK124 Steam Locomotive**: 2-6-2T tank locomotive silhouette with side water tanks, red buffer beams, `CK124` number plates, animated connecting rods, smoke particles, and synthesized Web Audio steam whistle.
- **3 Lighting & Sky Modes** (`Q` / `W` / `E`):
  - `晴朗白昼` (Clear Daylight)
  - `金色黄昏` (Golden Dusk)
  - `星夜灯火` (Starry Night with UnrealBloom glow, streetlamps & fireflies)
- **4 Camera Views** (`1`–`4`):
  - `全景环岛` (Panorama Orbit)
  - `火车 · 第三人称` (Train Third-Person Chase)
  - `火车 · 第一人称` (Train First-Person Cab)
  - `飞艇甲板` (Airship Deck)
- **Interactive Controls**: Train speed slider, whistle (`Space`), and HUD toggle (`H`).

## Run Locally
Open `index.html` directly in a modern browser, or serve via any static HTTP server:
```bash
python -m http.server 8799
```
